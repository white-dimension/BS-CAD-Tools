# BS-CAD-Tools 使用说明

## 命令列表

| 命令 | 用途 |
|------|------|
| `ShowPanel` | 显示主工具面板 |
| `LY` | 打开图层管理器 |
| `FIXFONTS` | 修复全图文字字体 |
| `TS` | 标准化文字（设置为微软雅黑） |
| `BZ` | 建立标准环境 |
| `SETBYLAYER` | 全图对象设为 ByLayer |

## 加载方式

1. AutoCAD 中运行 `NETLOAD`
2. 选择 `BS.CAD.Tools.dll`
3. 输入对应命令即可使用

## 输入法自动切换

插件加载后自动检测系统输入法：
- 进入文字编辑 → 自动切换中文输入法
- 退出文字编辑 → 自动切回英文
