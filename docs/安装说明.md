# BS-CAD-Tools 安装说明

## 方式一：NETLOAD 测试加载

1. 在 Windows 开发环境编译项目：

```bash
dotnet build src\BS.CAD.Tools\BS.CAD.Tools.csproj
```

2. 打开 AutoCAD。
3. 输入 `NETLOAD`。
4. 选择：

```text
src\BS.CAD.Tools\bin\Debug\net10.0-windows\BS.CAD.Tools.dll
```

5. 输入 `ShowPanel` 打开主面板，或输入 `LY` 打开图层管理器。

## 方式二：自动加载安装

1. 先完成编译。
2. 以管理员身份运行 PowerShell。
3. 在仓库根目录执行：

```powershell
.\installer\setup_autoload.ps1
```

脚本会将插件复制到：

```text
C:\ProgramData\Autodesk\ApplicationPlugins\BS-CAD-Tools.bundle\Contents\BS.CAD.Tools.dll
```

并生成：

```text
C:\ProgramData\Autodesk\ApplicationPlugins\BS-CAD-Tools.bundle\PackageContents.xml
```

重启 AutoCAD 后插件会自动加载。

## 常用命令

- `ShowPanel`：打开 CAD助手主面板
- `LY`：打开图层管理器
- `FIXFONTS`：修复全图文字样式
- `TS`：标准化文字
- `SETBYLAYER`：全图对象属性随层
- `BZ`：标准环境初始化测试入口
