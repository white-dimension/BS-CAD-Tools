# BS-CAD-Tools 开发说明

## 项目结构

```
BS-CAD-Tools/
├─ src/
│  └─ BS.CAD.Tools/       ← 源代码
│     ├─ Commands/        ← AutoCAD 命令入口
│     ├─ Services/        ← 业务服务
│     ├─ Views/           ← WPF 界面
│     ├─ Models/          ← 数据模型
│     └─ Utils/           ← 工具类
├─ installer/             ← 部署脚本
├─ docs/                  ← 文档
│  └─ archive/            ← 历史归档
└─ external/              ← 外部依赖
   └─ BS-CAD-Standard/    ← 标准规则（预留）
```

## 开发环境

- .NET 10.0 SDK
- AutoCAD 2027
- 引用 AutoCAD .NET API 包 (AutoCAD.NET v26.0.0)

## 构建

```bash
dotnet build src/BS.CAD.Tools/BS.CAD.Tools.csproj
```

## 命名空间

- 根命名空间：`BS.CAD.Tools`
- 命令类：`BS.CAD.Tools.Commands`
- 服务类：`BS.CAD.Tools.Services`
- 视图类：`BS.CAD.Tools.Views`
- 模型类：`BS.CAD.Tools.Models`
- 工具类：`BS.CAD.Tools.Utils`
