## 本次整理：工具可用性优化

- 主工具面板重新分组：图层工具、输入法、字体工具、图纸清理。
- 新增“打开图层管理器 LY”按钮，日常入口更直接。
- 为危险操作增加确认弹窗：`SETBYLAYER`、`FIXFONTS`、`TS`、`BZ`。
- 主面板新增底部状态提示，显示最近执行的命令或错误。
- 图层管理器默认面板宽度调整为 620，更适合显示图层表格。
- 图层删除、图层合并增加二次确认，降低误操作风险。
- 日志和模板路径从 `MyAutoCadTools` 更新为 `BS-CAD-Tools`。
- 本轮未对接 `BS-CAD-Standard`，未实现图层标准 JSON 读取。
- 安装脚本和自动加载配置已从旧名称 `MyAutoCadTools.dll` 更新为 `BS.CAD.Tools.dll`。
