# CAD助手 研发进度报告

## 项目概况
为 **AutoCAD 2027** 量身定制的 **Win11 暗黑风格** 全功能侧边栏工具箱，通过图层管家、输入法、字体等核心交互实现设计效率翻倍。

## 技术栈
| 项目 | 技术 |
|---|---|
| 语言 | C# (.NET 10.0-windows) |
| UI 引擎 | WPF |
| CAD 接口 | AutoCAD .NET API (ObjectARX) |
| 版本 | **V5.3** |

---

## 已完成功能

### A. 全自动输入法管家
- 进入文字编辑场景自动切中文输入法，退出切回英文
- 支持 Win32 原生 PostMessage 无感切换

### B. 万能字体切换引擎
- 一键修复图纸问号/乱码，TTF/SHX 智能配对
- 全图文字批量标准化

### C. 超级图层管家

#### 图层属性面板
- 全属性矩阵：状态 ✔ / 开关 💡 / 冻结 ❄️ / 锁定 🔒 / 打印 🖨️ / 颜色 / 线型 / 线宽 / 透明度 / 新视口冻结 🧊 / 物体数 / 说明
- 实时同步：监听 AutoCAD 原生图层管理器改动，500ms 防抖自动刷新
- 列管理器：表头右键勾选/隐藏任意列
- 可拖拽列宽，表头文字清晰居中

#### 图层操作
| 功能 | 描述 |
|---|---|
| 隔离图层 | 只显示选中图层，其余全部关闭 |
| 取消隔离 | 一键恢复全部图层 |
| 冻结其他 | 冻结除选中外的所有图层（跳过当前层） |
| 锁定其他 | 锁定除选中外的所有图层 |
| 选中该层物体 | 通过 SelectionFilter 选中该层所有物体 |
| 合并图层 | 选 ≥1 个图层合并到目标图层（物体迁移 + 删原层） |
| 批量改名 | 添加前缀/后缀/查找替换 |
| 批量改属性 | 统改颜色/线型/透明度 |

#### 图层状态快照
- 保存/恢复当前所有图层开关、冻结、锁定状态
- 跨图纸持久化

#### 图层模板
- 保存当前图层名列表为模板文件
- 从模板批量创建图层（新图一键导入标准图层架构）

#### 图层走查
- ◀ ▶ 逐层隔离浏览，审图利器

#### 查找空图层
- 一键筛选物体数为 0 的图层，可批量删除

#### 导出
- 图层列表复制到剪贴板（名称/开关/冻结/锁定/颜色/线型/线宽/物体数/说明）

#### 颜色选择器
- 自定义 Win11 暗黑圆角对话框
- 26 组分类，255 个 ACI 索引色，每组标注色号
- 深色滚动条，实时当前/变更对比
- 点击颜色方块即可替换 AutoCAD 原生 ColorDialog

#### 搜索增强
- 支持图层名称 / 颜色索引号 / 线型名称 / 物体数量 多字段模糊搜索

#### 右键菜单
- 筛选前缀 / 筛选颜色 / 添加过滤标签
- 设为当前图层 / 重命名 (F2) / 隔离 / 取消隔离
- 冻结其他 / 锁定其他 / 选中物体
- 合并图层 / 批量改名 / 批量改属性 / 删除

#### Win11 暗黑风格
- 所有弹窗统一圆角矩形（10px 外框 + 6px 按钮）
- 自定义标题栏可拖拽，✕ 关闭按钮
- 深色背景下拉选择框，ItemContainer 暗色样式
- 物理按压缩放动画 (ScaleTransform 0.94)
- 无白色滚动条

#### 稳定性
- `DocumentLock` + `Transaction` 同步安全事务
- `AppDomain.UnhandledException` 全局崩溃捕获 + MessageBox 弹窗
- 文件日志系统（%APPDATA%\MyAutoCadTools\debug.log），2 秒去重防抖
- 物理追踪日志 (trace.log) 用于崩溃定位
- WPF 资源冻结技术防止跨线程渲染崩溃
- 所有 FindResource 调用受 try-catch 保护
- doc 空引用全路径检查
