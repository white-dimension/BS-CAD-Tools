# CAD助手 UI 设计规范

## 设计原则
- **Win11 暗黑风格**：所有界面采用深色背景 + 低对比度边框
- **圆角矩形**：交互元素统一使用圆角，视觉柔和
- **物理反馈**：按钮按下有缩放动画 (ScaleTransform 0.94)
- **纯净视觉**：隐藏滚动条，暗色右键菜单，无多余装饰

## 按钮动画

### Win11ButtonStyle（通用按钮）
```
默认:   ScaleTransform(1.0, 1.0), Background=#333333
悬停:   Background=#444444
按下:   ScaleTransform(0.94, 0.94)
```

### IconButtonStyle（表头图标按钮）
```
默认:   ScaleTransform(1.0, 1.0), Background=Transparent
悬停:   Background=#20FFFFFF (10% 白色)
按下:   ScaleTransform(0.94, 0.94)
```

### FilterButtonStyle（过滤标签按钮）
```
默认:   Background=#333333, Padding=20,10
选中:   Tag="active" → Background=#0078D4 ← Trigger 驱动
```

## 对话框规范

### 基础参数
| 属性 | 值 |
|---|---|
| WindowStyle | `None`（自定义标题栏）|
| AllowsTransparency | `True` |
| 背景 | `Transparent`（圆角由 Border 提供）|
| 外框圆角 | `10px` |
| 最小宽度 | `380px` |
| 标题栏 | 可拖拽，右侧 ✕ 关闭 |
| 输入框 | Border 包裹，圆角 `6px` |
| 按钮 | 取消 `#444` / 确定 `#0078D4` |

### 文字输入对话框（Show）
- 标题栏 36px + 提示文字 + 输入框 + 按钮行
- 高度约 `175px`（适配 2 行提示）

### 下拉选择对话框（Select）
- 标题栏 36px + 提示文字 + ComboBox + 按钮行
- 高度约 `230px`
- ComboBox 可编辑、可搜索

|---|---|

## 交互规范

### 表头右键
- 弹出列可见性菜单（11 列），勾选/取消切换显示
- 打开时自动同步当前可见状态

### 行右键
- 筛选前缀 / 筛选颜色 / 添加过滤标签 / 设为当前 / 重命名 / 删除

### 双击
- 图层行 → 设为当前图层

### F2
- 选中图层 → 直接弹出重命名对话框

### 点击列单元格
- 颜色方块 → AutoCAD 原生颜色选择器
- 线型名称 → 下拉选择
- 透明度数值 → 输入 0-90
- 状态图标 → 切换开关/冻结/锁定/打印/新视口冻结
